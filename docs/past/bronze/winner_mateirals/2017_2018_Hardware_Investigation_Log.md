## Key Disambiguations Resolved During Investigation

1. **`suju.online` ≠ Junction 2017**: Disambiguated as a **2016** Junction project (`2017_2018` attribution rejected).
2. **Team Glados Year Separation**: Confirmed `Signvision` (traffic-sign CV/TF + STARA 2nd) won **Junction 2017 Overall**, while `Oneiro` (Raspberry Pi ALPR + Ensto Chago EV Airbnb + Ensto 1st) won **Junction 2018 Overall**.
3. **`Team Health.io` == `Help.io` (`mnimants/junction2018`)**: Proved via Movesense serial logs, University of Latvia member rosters (`Cīrulnieks, Nīmants, Viļķels, Cibuļskis, Mednis`), and Intel BlueZ Mesh kit configs that Movesense's *"Team Health.io"* and Swift code's `"Help.io"` are the exact same team that won **Intel Bluetooth Mesh 1st**, **IoT Track Overall 1st**, and **2nd Overall** in 2018 — building on four members' prior 2017 Movesense win (**ReCover**).
4. **Ericsson (`Saved by IoT`) vs. Help.io**: EU H2020 **SOFIE** explicitly attributes drone-deployed long-battery Bluetooth mesh nodes to the **Ericsson Smart Cloud** winner, distinct from `Help.io`'s wearable patient triage mesh.
5. **False-Positive Repo Matches Checked & Rejected**: `kvld/junction2018` = K-Group iOS diet app (not Alepa robot hack); `ecoPets` = Fortum energy challenge (not Helvar 2017 winner).
