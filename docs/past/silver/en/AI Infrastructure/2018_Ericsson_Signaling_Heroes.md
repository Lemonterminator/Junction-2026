## Full Original Challenge Name

Signaling Heroes

## Challenge Description

Ericsson challenges you to step into the shoes of a Cyber Detective with the aim of spotting the malicious network nodes attacking the mobile network endpoints. To achieve this, you need to create an anomaly detection solution to detect attack messages from signaling traffic. The solution is supposed to include a complete pipeline from the network capture dataset to the result that points out the attacks from the message data and the malicious nodes in the network.
