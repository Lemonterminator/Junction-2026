# [2018] Ericsson — Signaling Heroes

## Metadata

- **Year**: 2018
- **Challenge Partner**: Ericsson
- **Original Historical Track**: AI & Data
- **2026 Target Track**: Data Track
- **Sub-theme**: VI. Healthcare, Biometrics, Security & Gameplay Data Science
- **Core Theme**: Attack Packet Feature Extraction and Anomaly Detection Based on Mobile Network Signaling Capture Dataset (Network Capture Dataset)
- **Classification Rationale**: Requiring the construction of a complete data science pipeline to precisely identify anomalous attack patterns and locate malicious network nodes from massive underlying signaling message datasets.

---

## Full Original Challenge Name

Signaling Heroes

## Challenge Description

Ericsson challenges you to step into the shoes of a Cyber Detective with the aim of spotting the malicious network nodes attacking the mobile network endpoints. To achieve this, you need to create an anomaly detection solution to detect attack messages from signaling traffic. The solution is supposed to include a complete pipeline from the network capture dataset to the result that points out the attacks from the message data and the malicious nodes in the network.
