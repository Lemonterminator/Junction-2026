## Full Original Challenge Name

Who needs a light switch? - Automate the whole process of controlling light.

## Challenge Description

People are too lazy to control the lights manually! Help us to either automate the whole process or at least by giving the user a really frictionless control. Test your innovativeness by finding new ways to increase people well-being with intelligent algorithms and/or the newest sensors…

## Challenge Insights

To help you accomplish this, we will provide you with top of the line professional lighting system in the Smart Room. Our REST API can be used to control the light level, color temperature, RGB color and fade times. Our API also provides you with live feed from various sensors and input devices:
 
 1. Light intensity sensors
 2. Any button presses in the lighting system
 3. Passive infrared (PIR) sensors
 4. Mood rings http://www.moodmetric.com
 5. Infrared camera http://www.flir.com/cores/lepton/
 
 You are also free to use any sensors in your own laptops or mobile devices

## Judging Criteria

1. Automatic and advanced lighting control with no need for user commands.
 2. Optimizing the lighting system by learning from the sensor data.
 3. New user interfaces to control lighting effortlessly.

## Prizes
