## Full Original Challenge Name

Sitra wellness challenge - Mix, shake, twist and present wellness data in an intuitive and clever form using the latest data lake technologies and analytics.

## Challenge Description

Your team will have an Azure data lake set up with two separate data sets: 1)  synthetic health data and 2) sensor data combining wellness data and data from IoT sensors. Your task is to build an application which either present parts of this data in a clever new way, to interact with the data or brings more real-time data using sensors or social media to the data lake. You have all the flexibility to be creative as long as your solution uses the given technologies and has potential to increase wellness.

## Challenge Insights

Before the event we will publish the meta data of the datasets which will be uploaded to the datalake. During the event you will have technical support to use the datalake and analytics tools as well as support for the datasets.

## Judging Criteria

Artificial intelligence and the use of big data will revolutionize healthcare as we know it. In our challenge you could do for example data visualizations, unsupervised clustering, supervised machine learning, data profiling or secure data directory for medical research.
