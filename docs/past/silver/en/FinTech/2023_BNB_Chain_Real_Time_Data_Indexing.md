## Full Original Challenge Name

Real-time data indexing

## Challenge Description

The challenge with existing data indexing protocol is the turnaround time to fetch the data, process data and visualize it. This problem is quite evident, especially for NFTs where users require real-time, fast, reliable information to make the decision to flip them. A potential solution could be using deep learning models to learn from the existing data and use pattern recognition to predict a probable state of the chain that the user might use to make a decision in time. The visualization of this data is critical for a sleek user experience. (Current Challenges: lack of speed, accuracy, coverage, stability, excessive cost)
