## Full Original Challenge Name

Where the #?! is it? – RFID Helps. - Create a navigation app.  by using RFID tags.

## Challenge Description

Nowadays, technology makes possible to locate the locations of the items. By using this technology, we can facilitate and enhance the everyday lives of the people and businesses. We can create a clear view of the data.

## Challenge Insights

Finn-ID controls RFID readers and stores raw data on the location of the items. The location information can be read through the Finn-ID Rest service, which is used during the challenge. Participants in the challenge can be very innovative how they want to present the items to the user. The challenge can be used with 2D view as well as AR technology (eg Google ARCore)

We bring with us among other things: 
- RFID readers and other accessories
- Several Items with RFID tags
- Finn-ID Rest service (location and item
- Vuzix M300 Smart glasses
- Android OS, v7.0 or later smartphone
- Honeywell mobile devices
- Toshiba printers

## Judging Criteria

What are all the innovative ways how can we improve our customers' experience by utilizing RFID technology?
