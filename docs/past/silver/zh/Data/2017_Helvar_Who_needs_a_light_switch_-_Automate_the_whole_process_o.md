## 挑战描述 (Description)

人们太懒了，不想手动控制灯光！帮助我们实现整个流程的自动化，或者至少为用户提供真正无缝的控制体验。通过寻找新方法，利用智能算法和/或最新传感器来提升人们的福祉，测试你的创新能力……

## 挑战洞察 (Challenge Insights)

为帮助你实现这一目标，我们将在智能房间中为你提供顶级的专业照明系统。我们的 REST API 可用于控制光照水平、色温、RGB 颜色和渐变时间。我们的 API 还为你提供来自各种传感器和输入设备的实时数据流：
 
 1. 光照强度传感器
 2. 照明系统中的任何按钮按下
 3. 被动红外（PIR）传感器
 4. 情绪戒指 http://www.moodmetric.com
 5. 红外摄像头 http://www.flir.com/cores/lepton/
 
 你也可以自由使用自己笔记本电脑或移动设备中的任何传感器

## 评审标准 (Judging Criteria)

1. 无需用户命令的自动且先进的照明控制。
 2. 通过从传感器数据中学习来优化照明系统。
 3. 新的用户界面，实现轻松控制照明。
