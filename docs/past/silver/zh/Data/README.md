## 一、赛道定义与重组标准 (Track Definition & Reorganization Criteria)

**Data Track** 聚焦于海量结构化/非结构化数据工程、时序预测、地理空间分析、实时流式数据索引、多源开放数据融合、工业/城市数字孪生数据底座及行业数据价值变现。

### 重组与归类标准（Reorganization Criteria）
本目录完整覆盖了 `AI & Data` 赛道中所有以数据分析、预测建模、特征工程与可视化为核心的赛题，并从 `Sustainability`、`Urban & Mobility`、`Entertainment`、`Security`、`Education`、`Health`、`IoT & Hardware`、`Other` 中系统整合了 **57 道高价值数据挑战**，按六大业务与技术领域组织：
1. **能源、电网与工业时间序列预测及故障诊断**：如 Fortum 多客群电力消费高精度时序预测、Valmet x HSY 污水管网流量与电价预测、Digital BCG 能源危机数据分析、Outotec 冶金工厂声学/振动故障预测、Valmet 造纸机辊筒微米级几何测量分析、Oras 建筑用水 JSON 数据预测、Vaisala 气象数据融合、Denso 充电桩需求预测与异常检测。
2. **零售供应链、物流调度与可持续消费数据挖掘**：如 Relex 零售生鲜零浪费实时 POS 与视觉数据优化、Valio Aimo 20,000+ 餐饮客户拣货缺货概率预测、K-Group 与 CGI & Kesko 商超购物篮交易数据挖掘、QOCO 航空货运容量与行李全链路追踪数据、Fleetboard 重卡实时遥测数据、Cronvall 工业采购碳排数据、Outotec 材料环境足迹数据、Columbia Road 电商防错买数据分析。
3. **地理空间分析、城市大数据与客流态势感知**：如 McKinsey 地理空间分析与选址评分建模、Microsoft 芬兰多源开放数据科学、Business Finland 赫尔辛基 17 亿行城市动态与游客轨迹分析、Telia 电信人群流动大数据、Aalto 校园与大型活动实时 WiFi 客流预测、STARA 赫尔辛基市政维护与街道改造大数据、Tampere 城市交通引导数据、Visit Finland 国家公园小时级客流 CSV 预测、Aalto 开放空间与卫星遥感数据。
4. **建筑数字孪生、室内毫米波雷达/传感器网络与三维工程数据**：如 KONE x Granlund 万亿级建筑机电资产数据采集与数字孪生、Helvar & VTT 60GHz/24GHz 毫米波雷达与 RGB 骨骼多模态室内感知、Helvar 楼宇多源数据融合与传感器拓扑自动定位、Trimble 三维 BIM 工程数据、Peikko IFC 建筑元数据挖掘、Stara 市政建筑修缮工程数据管控。
5. **实时数据索引、企业分析平台、金融法规与开放数据经济**：如 BNB Chain 实时链上数据索引协议、SAS Viya 与 CI 360 企业级分析平台、Suomen Pankki 基于 Medallion 架构（Bronze/Silver/Gold）的 55GB 金融法规数据分析、Espoo 初创与大企业匹配算法及区域开放数据自动分析、Sitra 个人数据主权、TX Streamr Web3 数据工会变现、Gravity Team 加密市场多源信号与情绪定价分析。
6. **医疗健康、生物特征、网络安全与游戏行为数据科学**：如 CGI & 图尔库市独居老人防孤立精准推荐、Varian 放疗计划数据库分析、Sitra Azure 数据湖健康与传感数据分析、Huawei 穿戴传感器动作与情绪建模、Pixieray 智能眼镜 12 路红外眼动与行为关联分析、Pfizer x Aava 偏头痛发作生物信号预测、Ericsson 核心网信令异常检测与威胁情报数据流水线、D-Fence 钓鱼邮件分类、Kamu 与 Epic Games 实时游戏遥测数据挖掘、Veikkaus 体育统计数据建模。
