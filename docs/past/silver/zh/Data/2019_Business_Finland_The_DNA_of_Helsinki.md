# [2019] Business Finland — 赫尔辛基的DNA

## 元数据

- **年份**: 2019
- **挑战合作方**: Business Finland
- **原始历史赛道**: Urban & Mobility
- **2026 对应赛道**: Data Track
- **技术细分方向**: 三、地理空间分析、城市大数据与客流态势感知 (Geospatial Analytics, Urban Big Data & People Flow)
- **核心主题**: 挖掘赫尔辛基 17 亿行城市动态数据与港口游客轨迹，融合 POI、天气与 3D 城市模型优化交通
- **归类理由**: 源自 Urban & Mobility 赛道，开放高达 17 亿行赫尔辛基城市脉搏数据与港口游客移动数据集，结合交通流量、活动、天气等开放 API 揭示城市人群流动规律。

## 挑战完整题目

赫尔辛基的DNA

## 挑战描述 (Description)

深入探索赫尔辛基城市跳动心脏的17亿行数据。从真实的城市尺度环境中识别行为模式。寻找方法以提升对城市动态运作方式的认知。改善城市体验，造福人民和地球。

探索赫尔辛基港游客流动的大型数据集。发现关键兴趣地点和行为模型。寻找分析关键地点和区域之间人流的方法，以及优化城市服务（例如交通）的方式。

本挑战赛寻求创新的方式来可视化任何发现，以及通过结合不同来源的数据来发现有用见解的新颖方法。

## 可用资源 (Resources)

Business Finland 将提供：用于访问数据集的 REST API 和 API 密钥、API 文档、现场技术支持、指向各种来源的支持性开放数据 API 的链接，提供对兴趣点、事件、交通流量、天气、赫尔辛基 3D 模型和公共交通的访问。
