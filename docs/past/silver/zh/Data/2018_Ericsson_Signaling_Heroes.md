# [2018] Ericsson — 信号英雄

## 元数据

- **年份**: 2018
- **挑战合作方**: Ericsson
- **原始历史赛道**: AI & Data
- **2026 对应赛道**: Data Track
- **技术细分方向**: 六、医疗健康、生物特征、网络安全与游戏行为数据科学 (Healthcare, Biometrics, Security & Gameplay Data)
- **核心主题**: 基于移动网络信令抓包数据集（Network Capture Dataset）的攻击报文特征提取与异常检测
- **归类理由**: 要求构建完整的数据科学流水线，从海量底层信令消息数据集中精准识别异常攻击模式并定位恶意网络节点。

---

## 挑战完整题目

信号英雄

## 挑战描述 (Description)

Ericsson 挑战你扮演网络侦探，目标是识别攻击移动网络端点的恶意网络节点。为此，你需要创建一个异常检测解决方案，从信令流量中检测攻击消息。该解决方案应包含从网络捕获数据集到结果的完整流水线，结果需从消息数据中指出攻击以及网络中的恶意节点。
