# [2018] Outotec — 我听见工厂里的声音

## 元数据

- **年份**: 2018
- **挑战合作方**: Outotec
- **原始历史赛道**: Sustainability
- **2026 对应赛道**: Data Track
- **技术细分方向**: 一、能源、电网与工业时间序列预测及故障诊断 (Energy, Grid & Industrial Time-Series Forecasting)
- **核心主题**: 基于冶金工厂真实音频、运动传感器数据与历史故障事件的工业预测性维护与可视化
- **归类理由**: 源自 Sustainability 赛道，提供高温高能耗金属冶炼厂的真实声学（Audio）、运动（Motion）数据及故障记录，探索多模态工业传感数据与故障之间的相关性及操作员可视化引导。

## 挑战完整题目

我听见工厂里的声音

## 挑战描述 (Description)

在远离Junction的某个地方，有一座工厂，生产着我们日常所需的贵重金属。这是一个复杂的过程，需要消耗大量能源并处于极高温度下，其中可能出现问题，有可能对人员和设备造成损害。基于提供的音频和运动数据以及故障事件，您能否诊断工厂的运行状况，并预测未来的故障，或者预防它们？您能否将数据可视化，使其能够向操作员传达信息，帮助安全地指导他们？我们甚至不知道数据与故障之间是否存在任何关联（理论上应该存在），因此我们重视良好的尝试以及处理和可视化数据的巧妙新方法。让工厂成为更安全的工作场所！
