## 挑战描述 (Description)

你知道全球几乎所有道路的共同点是什么吗？卡车已经去过那里。现在，你的代码也可以到达那里！如今，开发者可以轻松获取实时卡车数据来构建应用程序。
只有你和我们的 SDK。你会选择勇敢面对命运，前往代码从未涉足的地方吗？那么，请创建一个利用我们 SDK 为 Mercedes-Benz Truck App Portal 提供的实时车辆数据的 Android 应用程序，帮助物流行业最大化其效率。
