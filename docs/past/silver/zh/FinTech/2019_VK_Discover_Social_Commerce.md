## 挑战完整题目

探索 VK 社交电商

## 挑战描述 (Description)

全球最大的在线市场，成立于亚洲，与欧洲最大的社交网络相遇：如何搭建 VK 上的社交电商，为用户创造卓越的购物体验。

VK 提供社交体验平台，包括沟通、内容、主题社区和实用服务等。AliExpress 为消费者和企业提供海量商品，除此之外，还提供云计算和支付服务。想象一下，将所有结合社交平台和全球最大在线市场优势的解决方案汇聚一堂。你一直梦想的社交平台购物体验是什么样的？

## 可用资源 (Resources)

VK 将提供：VK API（包括社交图谱功能）和 AliExpress 商品 API。我们的导师将协助解答有关 API 使用的问题。我们还建议参与者使用 VK Mini Apps 平台，该平台基于 VK UI 组件库，可轻松创建跨客户端服务。
