## 挑战完整题目

超越 MobilePay 的创新

## 挑战描述 (Description)

MobilePay 为日常支付场景提供解决方案——订阅和发票是其最新产品之一。相关的 MobilePay API 自 2017 年就已进入市场，允许个人用户通过手机随时随地支付订阅费用和发票。
为了创新并将我们的产品拓展到新的场景，我们提出一项挑战：为面向北欧市场的 API 改进或创造新的用例。
我们希望你们不受束缚地展翅高飞：请随意重新思考甚至是最基础的部分——从用户旅程到商户互动！面对 440 万注册用户，你会怎么做？
