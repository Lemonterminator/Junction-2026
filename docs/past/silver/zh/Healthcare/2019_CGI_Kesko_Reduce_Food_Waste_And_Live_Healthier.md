# [2019] CGI & Kesko — 利用数据帮助人们减少食物浪费，过上更健康的生活

## 元数据

- **年份**: 2019
- **挑战合作方**: CGI & Kesko
- **原始历史赛道**: Sustainability
- **2026 对应赛道**: Healthcare Track
- **技术细分方向**: 营养膳食、卫生健康与健康生活方式 (Nutrition, Hygiene & Healthy Lifestyle)
- **核心主题**: 利用食品配料表 API 与购物篮数据帮助公众改善膳食营养结构、践行健康生活方式
- **归类理由**: 虽原属 Sustainability 赛道，但以“Live Healthier Lives（过上更健康的生活）”为双核心目标之一，开放 Kesko 食品配料与营养数据 API 辅助个性化健康饮食管理。

---

## 挑战完整题目

利用数据帮助人们减少食物浪费，过上更健康的生活

## 挑战描述 (Description)

今年在 Junction，我们自豪地宣布 CGI 与 K Group——全球最具可持续性的贸易行业公司——携手合作。我们共同希望找到创新方法，支持消费者让日常生活更可持续、更健康。

想象一下，利用杂货零售和其他零售领域的交易数据来创建新服务，支持人们在日常生活中做出更健康、更可持续的选择。我们能否找到新方法来应对减少食物浪费和过上更健康生活方式这一全球性问题？

## 挑战洞察 (Challenge Insights)

人们正努力在日常生活中和消费中做出更可持续的选择。健康的选择以及能够减少食物浪费，正成为现代社会中越来越重要的价值观。

众所周知，气候变化和排放增加引发了许多人的担忧。然而，缺乏知识和工具限制了人们采取措施。是时候行动了，成功需要合作。

## 可用资源 (Resources)

Kesko 将提供：为挑战参与者提供多个 API，例如搜索、食材、定价和可用性。还将提供其他文件和文档，例如完全匿名的购买篮数据。
