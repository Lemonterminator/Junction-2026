# [2023] Google Cloud (side challenge) — [侧边挑战] Google Cloud 支线任务

- **年份**: 2023
- **挑战合作方**: Google Cloud (side challenge)

- **2026 对应赛道**: AI Infrastructure Track (by Verda)

- **归类理由**: 2023 年 Google Cloud 全场支线挑战，考察开发者如何组合云端可扩展基础设施、Serverless 技术与 ML 工具支撑业务负载。

---

## 挑战完整题目

[侧边挑战] Google Cloud 支线任务

## 挑战描述 (Description)

在你的黑客松项目中使用 Google Cloud。利用最先进的机器学习工具、可扩展的基础设施、各种无服务器技术以及易于使用的 DevOps 工具，以便你可以专注于你的项目挑战。解决问题的方法往往不止一种。请花时间仔细考虑“你要解决的问题是什么”、“解决方案将帮助谁”。一旦你缩小了这些问题的答案范围，就更容易开始选择最适合你的技术。

## 评审标准 (Judging Criteria)

为了获得奖品，我们期望你展示出创造性和创新性的方式，将 Google Cloud 服务结合到你的解决方案中。

## 奖项设置 (Prizes)

获奖者将获得一些 Google 周边礼品。

## 可用资源 (Resources)

我们将提供 Google Cloud 项目和账户，并附带补充 credits，供你的团队在活动期间使用。来自赫尔辛基办公室的本地 Google 工程师将亲临 Junction 现场，回答你的问题并帮助你开始使用你的云项目。
