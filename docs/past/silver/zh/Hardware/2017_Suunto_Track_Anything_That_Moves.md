# [2017] Suunto — 追踪任何移动的事物——基于 Movesense 构建运动、健康或其他领域的追踪概念

## 元数据

- **年份**: 2017
- **挑战合作方**: Suunto
- **原始历史赛道**: IoT & Hardware
- **2026 对应赛道**: Hardware Track (by Arduino)
- **技术细分方向**: 可穿戴设备、运动与生物传感器 (Wearables, Motion & Biometric Sensors)
- **核心主题**: Movesense 可编程运动传感器与 C++ 嵌入式固件开发
- **归类理由**: 原属 IoT & Hardware 赛道。围绕 Suunto Movesense 可编程运动传感器硬件、烧录调试夹具（Programming Jigs）及嵌入式 C++ 固件与移动端 REST/BLE 接口开发，是典型的微型传感器与可穿戴硬件开发挑战。

## 挑战完整题目

追踪任何移动的事物——基于 Movesense 构建运动、健康或其他领域的追踪概念

## 挑战描述 (Description)

世界上充满了移动的事物——无论是运动员的身体或运动装备、生产线上的机器、交通中的桥梁、我们日常生活中的任何人，还是我们能想象到的任何其他事物。通常，了解这些事物如何以及何时移动——或者不移动——会非常有价值。Movesense 提供可编程的运动传感器、API 和软件库，使您能够快速构建自己的传感器功能和移动应用程序，以追踪任何移动的事物。帮助世界保持移动！

## 挑战洞察 (Challenge Insights)

参与者将有机会为 Movesense 传感器构建应用程序，并为 iOS 和 Android 构建兼容的移动应用。传感器和手机的示例应用支持原始数据收集，并展示如何使用传感器和移动设备处理和存储数据。整个系统基于简单的 REST API。传感器使用 C++ 编程。将提供与 IBM Bluemix 和 Microsoft Azure 的数据连接。
我们将提供：
- 一批 Movesense 传感器，足够所有项目使用。如果您向此挑战提交项目，您使用的传感器将在黑客松后归您所有。
- 用于快速上传和调试传感器应用程序的编程夹具
- 我们的 Movesense 软件专家支持您的工作

## 评审标准 (Judging Criteria)

运动追踪如何帮助优化力量、速度、技术、平衡、敏捷性、战术或当今尚未测量的任何其他特定或通用运动表现领域的训练？
健康和福祉呢？要过上健康的生活或在健康问题后恢复，我们需要了解的远不止每日步数和卡路里。您能否通过运动追踪提高我们的生活质量？
或者您更愿意追踪人类以外的其他事物？优化生产过程？数字化农业？改善物流？世界上有太多移动的事物。但是，何时以及如何移动或不移动？嗯，这就是问题所在。

## 奖项设置 (Prizes)

所有提交基于 Movesense 项目的团队都可以保留开发中使用的 Movesense 传感器。作为获胜奖品，我们将为三个类别中最佳解决方案的每位团队成员颁发最新的 Suunto Spartan 手表：1. 运动 2. 健康与福祉 3. 通用物联网。此外，拥有运动与日常健康商业可行解决方案的团队将有机会与 Suunto 洽谈合作选项。

## 关于合作方 (About Company)

Suunto 是一家芬兰制造商，生产世界知名的运动手表、潜水电脑和适用于最恶劣条件的精密仪器。我们的新计划 Movesense 是一个开放开发环境和可编程传感器，用于运动追踪及其他传感，服务于运动及更广泛领域。借助 Movesense，您可以快速且经济高效地将自己的传感器创意商业化，而无需担心硬件开发和制造。
