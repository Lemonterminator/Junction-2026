## 挑战描述 (Description)

如今，技术使得定位物品位置成为可能。通过使用这项技术，我们可以促进和改善人们和企业的日常生活。我们可以创建清晰的数据视图。

## 挑战洞察 (Challenge Insights)

Finn-ID控制RFID读取器并存储物品位置的原始数据。位置信息可通过Finn-ID Rest服务读取，该服务将在挑战期间使用。挑战参与者可以非常创新地展示物品给用户的方式。挑战可以使用2D视图以及AR技术（例如Google ARCore）。

我们带来的东西包括：
- RFID读取器和其他配件
- 多个带有RFID标签的物品
- Finn-ID Rest服务（位置和物品）
- Vuzix M300智能眼镜
- Android OS v7.0或更高版本的智能手机
- Honeywell移动设备
- Toshiba打印机
