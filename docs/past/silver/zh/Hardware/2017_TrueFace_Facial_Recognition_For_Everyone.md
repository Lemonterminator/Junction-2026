## 元数据

- **挑战合作方**: TrueFace.ai

## 挑战完整题目

面向所有人的人脸识别——使用一个或多个 TrueFace.ai 人脸识别 API 创建应用

## 挑战描述 (Description)

人脸识别正在席卷一切。就连 Apple 也参与其中！从刷脸支付、刷脸认证、情绪检测、面部特征检测、监控、自动签到等等，用例无穷无尽。

参与其中，应用我们深度学习驱动的人脸识别技术，打造你自己的应用。

## 挑战洞察 (Challenge Insights)

参与者将使用以下一项或多项组合，创建富有创意、有价值且令人印象深刻的应用：

人脸检测（检测图像中的一张或多张人脸）

人脸匹配（将一张人脸与数据库中的面部进行匹配——例如可用于替代登录）

人脸识别（识别一张或多张人脸——例如可用于在人群中识别个体）

原始特征点检测（识别面部特征，例如可根据脸型推荐眼镜类型）

防欺骗检测（检测攻击行为，即有人试图用他人照片欺骗技术）

活动期间，我们将提供 Slack 和电子邮件支持，涵盖技术和非技术方面。
