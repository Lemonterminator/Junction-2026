# [2025] Figma — 使用 Figma Make，通过提示词将任何你能想象到的东西变成代码。

## 元数据

- **年份**: 2025
- **挑战合作方**: Figma
- **原始历史赛道**: Education
- **2026 对应赛道**: Agentic AI Track
- **技术细分方向**: 四、生成式创意、Prompt-to-Code 与 AI 原生游戏智能体 (Generative Creativity, Prompt-to-Code & Playable AI)
- **核心主题**: 基于 Figma Make 与 Figma MCP 的自然语言生成可交互原型与前端代码工作流
- **归类理由**: 源自 Education 赛道，要求利用 Figma Make、Figma AI 及 Figma MCP（Model Context Protocol）实现从自然语言提示词直接生成高完成度 Web 应用与前端工程代码。

---

## 挑战完整题目

使用 Figma Make，通过提示词将任何你能想象到的东西变成代码。

## 挑战描述 (Description)

从一个想法开始，通过提示词快速构建出可用的原型或 Web 应用。

Figma Make 借助 AI 驱动的设计工具，让你将想法变为现实——在一个创意空间内生成、迭代并更快地构建。你能将创意边界推进多远？通过快速迭代和协作，你能获得哪些洞察、解决哪些问题？又如何通过设计质量实现差异化？Figma Make 挑战赛要求你突破边界，提升概念设计的速度与效率，打造一套开发工作流。分享你在过程中的创意洞察与收获，我们想看到你创造了什么，以及你是如何实现的。

## 挑战洞察 (Challenge Insights)

使用 Figma Make 加速你对新想法的探索、原型制作，并让你的项目脱颖而出。获胜项目将根据其最终作品的工艺与质量，从使用 Figma Make 的项目中选出。

## 评审标准 (Judging Criteria)

Figma Make 挑战赛的获胜者将展示使用 Figma Make 如何加速其工作流，并提升项目概念、设计以及前端体验的工艺水平。我们将仔细考察 Figma Make 如何被用于探索和验证概念、迭代和优化体验，或创造优雅而精致的设计。

可选加分项：
创造性地使用 Make
优雅、高质量的设计与交互
关于 Make 如何用于提升创新和快速迭代过程的令人信服的洞察
使用多个 Figma 产品（例如 Figma AI、Figma MCP、设计等）可获得额外加分。

## 奖项设置 (Prizes)

Figma Make 挑战赛的获胜者将获得 3000 欧元现金奖励。

## 可用资源 (Resources)

Figma 将邀请来自 Figma Advocacy 团队和 Figma MCP 产品团队的导师出席活动，他们在产品设计、原型制作和产品开发方面拥有丰富经验。

Figma 将通过免费升级码为所有黑客松参与者提供 Figma Make 的访问权限。每位参与者可在黑客松期间将其 Figma 账户中的一个团队升级至 Figma Professional。此次升级将使参与者能够访问 Figma 的全套产品与 AI 工具，包括 Figma Make。

## 关于合作方 (About Company)

Figma 的平台帮助团队将想法变为现实——无论你是在头脑风暴、创建原型、将设计转化为代码，还是借助 AI 进行迭代。从想法到产品，Figma 赋能团队简化工作流、更快发布，并让全球各地的成员实时协作。
