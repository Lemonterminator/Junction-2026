## 一、赛道定义与重组标准 (Track Definition & Reorganization Criteria)

**Agentic AI Track** 聚焦于具备自主感知、推理规划、工具调用、多智能体协同（Multi-Agent Collaboration）与闭环行动能力的人工智能系统。

### 重组与归类标准（Reorganization Criteria）
本目录从 Hack Junction 2017–2025 全部 147 道历史赛题中，全面梳理了 `AI & Data` 赛道及 `Urban & Mobility`、`Sustainability`、`Security`、`Education`、`Entertainment`、`Finance`、`Other` 等跨赛道中的 **31 道智能体与生成式自动化挑战**，划分为五大核心方向：
1. **自主工作流编排与多智能体协同系统**：如 n8n 代码与无代码结合的 Agentic AI 工作流、Valmet x HSY 城市污水管网多智能体自主协同寻优、Valio Aimo 预测预警+多语言语音外呼协商 Agent、P&G 跨国营销活动自动化编排 Agent、Featherless.ai 开源大模型驱动的自主研究与洞察生成 Agent 工作流、Ericsson 5G 车队协同调度 Agent。
2. **合规审计、安全侦察与企业级知识智能体**：如 Traficom 航空法规端到端 AI 审计智能体（AAA）、WithSecure 面向 CISO 的软件信任度自主侦察与 MCP 评估 Agent、Suomen Pankki 金融监管法规冲突分析 GenAI 系统、Outokumpu 零幻觉可持续企业洞察助手、Ericsson 威胁情报自动猎手、Varian 放疗计划智能审查助手。
3. **多模态交互、语音陪伴与空间感知智能体**：如 Snap Spectacles 现实世界 AR 空间感知伴侣、Aalto 居家养老语音陪伴智能体、ElevenLabs 拟真语音交互智能体、SAP 企业级多模态客服 Agent、VK 未来人机交互助手、City of Espoo 创业顾问 Agent、赫尔辛基大学 AI 财商教练、Sitra 数字民主在线讨论自动引导智能体。
4. **生成式创意、Prompt-to-Code 与 AI 原生游戏智能体**：如 Figma Make（及 Figma MCP）Prompt-to-Code 研发智能体、Supercell AI-First 原生自适应游戏与具备记忆的智能 NPC、Starstuff 实时生成 3D 可玩世界智能体、Smartly.io 广告创意自动化裂变系统、Wolt 本地商业 AI 体验引擎。
5. **物理世界感知、机器视觉与自动化控制智能体**：如 KONE x Granlund 建筑机电资产视觉自动盘点智能体、Sensofusion 微秒级事件相机实时追踪智能体、Helvar 全自动无感照明与“建筑大脑”自主控制系统、TrueFace.ai 智能视觉身份核验、CGI x KONE x Meyer Turku 邮轮服务机器人编排。

### 2. [2025] Valmet x HSY — 智能流量优化

- **单题档案**: [2025_Valmet_x_HSY_Intelligent_Flow_Optimization.md](./2025_Valmet_x_HSY_Intelligent_Flow_Optimization.md)
- **原始赛道**: `Sustainability` | **所属子方向**: 一、自主工作流编排与多智能体协同系统 (Autonomous Workflow Orchestration & Multi-Agent Systems)
- **核心主题**: 多智能体协同（Multi-Agent AI）驱动的城市污水泵站实时自适应寻优控制
- **归类理由**: 源自 Sustainability 赛道，明确要求构建 Multi-Agent AI 系统（例如电价预测 Agent、调蓄池容量管理 Agent、泵群流量分配 Agent 协同博弈），通过 OPC UA 协议自主控制城市关键基础设施。

#### 挑战描述

构建一个多智能体AI，通过实时预测流入量、电价和流量动态，自主最小化废水泵送能耗——这是现代基础设施中最关键的流程之一。

每个城市都依赖看不见的系统维持运转——废水管理是其中最关键的一环。泵机不间断运行，消耗大量能源，同时面临流入量、暴雨和电价波动的混乱局面。如果这些网络能够自主思考呢？借助多智能体AI，Valmet和HSY邀请您将静态基础设施转变为能够实时预测、适应和优化废水流的活系统。

废水网络全天候运行且不能停止——但它们隐藏着智能优化的未开发潜力。每个泵站必须在恒定流量、有限存储和波动的电价之间取得平衡，同时保持对暴雨洪水的韧性。传统自动化遵循固定规则，忽略实时变化和预测。您的任务是构建一个多智能体AI系统，其中自主智能体根据每日电价规划泵送、协调泵站间的流量，并在不违反安全或工艺约束的前提下找到最节能的泵送策略。目标：让社会最关键的基础设施系统之一实现自我优化。

#### 可用资源

参与者将获得HSY的历史废水和流入数据集——涵盖多年环境变化的真实运营数据。系统通信和控制将通过OPC UA协议实现，这是安全实时数据交换的工业标准。来自Valmet、HSY和阿尔托大学的导师将在过程自动化、多智能体架构等领域提供实践指导，未来解决方案可通过数字孪生仿真进行测试。团队可自由使用任何AI框架——从强化学习环境到优化库或自定义智能体系统。

### 3. [2025] Valio Aimo — 零失误物流

- **单题档案**: [2025_Valio_Aimo_Zero-Fail_Logistics.md](./2025_Valio_Aimo_Zero-Fail_Logistics.md)
- **原始赛道**: `AI & Data` | **所属子方向**: 一、自主工作流编排与多智能体协同系统 (Autonomous Workflow Orchestration & Multi-Agent Systems)
- **核心主题**: 缺货风险预测 + 多语言语音优先（Voice-First）自主外呼协商 Agent + 多模态理赔
- **归类理由**: 要求构建端到端自主物流客服闭环：在拣货阶段检测到缺货时，AI Agent 自动以客户母语拨打电话/发信，主动提出替代品方案并即时确认修改，事后还能通过图像/视频自动处理理赔。

#### 挑战描述

利用预测性AI和多语言自动化客户服务（语音优先，文本其次）重塑配送可靠性。

Valio Aimo® 为超过20,000家专业厨房提供服务。如今，缺货商品往往在配送时或通过次日早上的手动电话才发现——为时已晚。在Junction 2025，我们寻求一种多模态AI解决方案（语音+文本+图像/视频），将中断转化为主动的客户体验，并大幅减少运营工作量。
目前，当订购的产品缺货时，客户只有在配送时或次日通过手动电话才会发现——为时已晚。目标是端到端自动化不完整配送流程。

你的挑战：

1. 拣货前预测——利用订单、库存和供应商/质量数据预测哪些商品可能缺货。

2. 拣货过程中主动通知——如果检测到短缺，AI代理以客户语言联系客户（电话/短信），提出替代方案，并即时确认变更。

3. 配送后补救——如果仍然发生短缺，AI触发事后外联并安排纠正性配送（当日追加配送或次日配送）。

4. 多模态索赔——探索语音、文本、图像和视频以处理配送差异。

影响：这不仅仅是减少手动工作，而是节省整个运营团队的工作量，同时提高客户满意度。

#### 可用资源

参与者将获得：

#### 挑战描述

你的挑战，如果你接受的话，是构建一个可持续的AI助手，用于动态信息检索和摘要，以支持关键业务用例。由于可持续AI是一个非常广泛的话题，为简单起见，本次挑战我们希望聚焦于可持续AI的两个方面：可信度和效率（我们在此将其作为生态可持续性的代理指标，通过更有限的能源使用和碳足迹来实现）。所以这不仅仅是构建一个信息检索助手并向一个巨大模型输入大量数据——那很简单。我们希望你们构建一个系统，以非常可信和可持续的方式实现同样的目标，这会让事情更具挑战性……因此你需要聪明地工作，而不仅仅是努力，因为“暴力破解”不会带来理想的结果。但嘿，这就是为什么这被称为挑战，我们知道你们能胜任！

可信度也有几个不同的方面。首先，它关乎使用正确的数据——尽可能正确的信息作为来源。我们都知道互联网不一定总是正确的……那么你如何知道哪些来源可信？但即使你拥有正确的信息，对其进行摘要也可能并不总能得到你想要的结果。生成模型相当常见的挑战之一是幻觉，实际上是为没有答案的问题编造结果。这会导致缺乏信任，甚至可能成为使用的障碍。你应该努力构建一个系统，使其输出基于你可以信任的来源，并避免幻觉，以确保系统的输出可靠且可信。

此外，众所周知，大型语言模型非常消耗资源。特别是训练模型往往消耗大量能源，但推理（当你使用模型时）也可能成本高昂——尤其是在大规模进行时。由于本次挑战的范围不包括从头构建模型，让我们聚焦于使用现有模型相关的计算成本——包括选择哪个模型以及如何使用它。这也是我们在实际应用中通常可以更好地控制的事情，因为即使我们使用现有的大型模型，我们绝对可以决定使用哪些模型以及如何使用它们。因此，尽管这是一组非常令人兴奋的技术，我们应该明智地使用它们，避免过度的资源消耗。在这种情况下，少即是多——最好的解决方案可能不会使用最大的模型或最广泛的上下文（或对模型进行非常大量的查询——总成本才是关键）——挑战的很大一部分是在仍然获得出色结果的同时优化资源使用。

这个解决方案如果成功，可以产生巨大的影响——并揭示如何以可持续的方式完成此类任务。因此，这不仅仅是构建一些非常酷和有用的东西，而是展示思考AI的可持续性如何能带来真正的积极影响！
