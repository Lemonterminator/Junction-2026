## 2. 核心产品与业务体系

Hostinger 构建了一个涵盖智能开发、底层算力、云端存储与自动化运维的全栈 Web 产品矩阵。

### 2.1 主打核心产品体系

#### 1. Hostinger AI Website Builder（智能建站与灵动编程平台）
- **Agentic Mode（智能体模式）与 Vibe Coding**：
  - 用户只需用自然语言输入对业务或应用的描述（例如：“为赫尔辛基一家主打极光观测的精品桑拿酒店制作一个预订网站”），AI 即可在数秒内生成具备完整交互架构、高保真响应式布局、符合品牌调性的文案与免版权高清视觉配图的原型。
  - 支持“氛围对话式实时修改”：随时通过自然语言指令微调版面组件、全局色彩与字体。
- **第三方 API 开放集成（Third-Party API Integrations）**：
  - 突破了传统无代码建站工具无法连接外部业务逻辑的死穴。支持通过 Agent 模式引导用户安全注入第三方 API（如 Stripe、PayPal 支付网关、自定义后端 Webhook），API Key 与敏感凭据均在隔离的专用安全输入层保管，防范 Prompt 注入泄露。

#### 2. Kodee — 基于 MCP 的 AI 系统运维管理员 (AI DevOps Agent)
- **Model Context Protocol (MCP) 原生集成**：
  - Hostinger 率先将开源 MCP 协议落地于商业生产环境，使 Kodee 能够作为标准的 MCP Server / Agent 运行。
- **全自主运维交互能力**：
  - Kodee 可以通过对话控制台安全执行约 **200 项复杂的 Linux VPS 管理操作**：包括配置 UFW 防火墙端口策略、管理与轮换 SSH 密钥、创建与回滚服务器快照（Snapshots）、实时诊断 CPU/内存暴涨原因、检测 Nginx/Apache 配置文件语法错误并执行自动化热重启。
  - 将过去需要资深 SRE 工程师手动执行的数十道 Shell 指令降维为一句话对话。

#### 3. Cloud & VPS Infrastructure（高性能云服务器与虚拟私有主机）
- **顶级硬件配置**：
  - 全线搭载最新一代 **AMD EPYC 高性能处理器** 与 **NVMe SSD 企业级固态存储**，网络端口带宽最高达 300Mb/s，保证极低的主机延迟与极高的 I/O 吞吐。
- **完全控制权与全球节点分布**：
  - 提供 100% 完整的系统 Root 访问权限。数据中心遍布欧洲（立陶宛、英国、法国、德国）、北美（美国）、南美（巴西）与亚洲（印度、新加坡、印度尼西亚），承诺 99.9% 在线率 SLA。

  - 支持 Debian, Ubuntu, AlmaLinux, Rocky Linux，以及预制 Docker、Node.js、Django、cPanel、WireGuard 等一键部署镜像。

#### 4. hPanel 自研面板与 Hostinger API
- **hPanel**：彻底摒弃臃肿复杂的传统 cPanel，从零自研的轻量化现代化控制面板，兼具极简设计与强大功能。

### 5.3 参赛者极速上手代码示例 (Quickstart)

```python
"""
Junction 2026: 3分钟调用 Hostinger API 实现云端基础设施的自动化管理与 DNS 调度
官方 API 规范: OpenAPI / Bearer Token
"""
import os
import requests

HOSTINGER_API_TOKEN = os.environ.get("HOSTINGER_API_TOKEN", "your_hostinger_api_token")
BASE_URL = "https://api.hostinger.com/v1"
HEADERS = {
    "Authorization": f"Bearer {HOSTINGER_API_TOKEN}",
    "Content-Type": "application/json"
}

def list_virtual_servers():
    """自动化获取当前账户下所有 VPS 服务器运行状态"""
    endpoint = f"{BASE_URL}/vps"
    print("[*] 正在向 Hostinger 云端请求 VPS 实例列表...")
    
    # 模拟真实调用请求
    try:
        response = requests.get(endpoint, headers=HEADERS, timeout=10)
        if response.status_code == 200:
            servers = response.json().get("data", [])
            print(f"[+] 成功获取 {len(servers)} 台 VPS 实例:")
            for server in servers:
                print(f" - ID: {server.get('id')}, 名称: {server.get('name')}, IP: {server.get('ip')}, 状态: {server.get('status')}")
            return servers
        else:
            print(f"[!] API 请求返回状态码: {response.status_code} (请检查 HOSTINGER_API_TOKEN 权限)")
            return []
    except Exception as e:
        print(f"[-] 网络连接异常: {e}")
        return []

def configure_dns_record(domain: str, record_type: str, name: str, content: str):
    """一键为黑客松项目添加公网子域名解析"""
    endpoint = f"{BASE_URL}/dns/{domain}/records"
    payload = {
        "type": record_type,
        "name": name,
        "content": content,
        "ttl": 300
    }
    print(f"[*] 正在为域名 {domain} 创建 DNS 解析: {name}.{domain} -> {content}...")
    try:
        response = requests.post(endpoint, headers=HEADERS, json=payload, timeout=10)
        if response.status_code in [200, 201]:
            print(f"[✓] DNS 解析配置成功！公网已秒级生效！")
        else:
            print(f"[!] 配置返回: {response.text}")
    except Exception as e:
        print(f"[-] 请求异常: {e}")

if __name__ == "__main__":
    print("=== Hostinger Cloud Infrastructure Quickstart ===")
    list_virtual_servers()
    # 示例: configure_dns_record("my-hackathon-project.com", "A", "api", "192.0.2.1")
```
