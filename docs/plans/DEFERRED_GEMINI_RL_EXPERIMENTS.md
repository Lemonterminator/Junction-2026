### W5：Gemini 失败教练与可选 RL

**未来重启依赖**：G2、G3a；生成接触训练数据需 G3b；API 调用和训练运行需要单独安排资源。**交付**：受约束的分析/仿真工具、课程记录、对照实验；本阶段本轮延期。

- [ ] W5.1 先实现离线失败包：关键帧、时间顺序、动作状态、模型版本、几何误差和独立结果。快速动作采用事件附近的关键帧，不能只依赖稀疏视频采样。
- [ ] W5.2 Gemini 返回结构化假设：证据、可能原因、替代解释、建议改变的单一条件、预期结果与推翻条件。证据不足允许返回未知。
- [ ] W5.3 工具限于 `inspect_episode`、`propose_scenario`、`run_sim_skill`、`evaluate_rollout` 等有 schema 和边界的接口；场景参数由代码验证。模型不执行任意代码，不直接调用实机执行器。
- [ ] W5.4 仿真动作由经过验证的技能/规划器实现，独立结果检查器验证成功。只保存完整、物理合法、无禁用事件、来源明确的轨迹；LLM 的文字动作不作为关节示教。
- [ ] W5.5 比较真实示教基线、固定仿真课程、Gemini 课程。固定总训练样本预算、优化步数、初始模型与真实留出集，分别记录真实/仿真比例；报告 API 成本、有效轨迹比例和真实成功率。条件允许时每组使用 3 个训练随机种子。
- [ ] W5.6 可选 RL 先做单工件、已定义容器的仿真残差控制，或重观察/抓取/停止的技能选择。连续残差可评估 SAC，批量仿真可评估 PPO；先根据环境和吞吐选一个，不同时建设多套 learner。
- [ ] W5.7 奖励依据独立的释放并稳定入碗结果，辅以时间/掉落代价；限制和终止条件由代码执行。检查悬停、重复计分、越界、穿模与利用成功检测漏洞等 reward hacking。
- [ ] W5.8 RL teacher 若使用物体真值，蒸馏学生时仅使用部署可获得的图像/状态/语言。比较原策略、残差策略及蒸馏学生；不把特权状态下的仿真成绩当成视觉部署成绩。

**G5 研究门**：失败分析/课程能力与训练增益分别验收。真实留出集改善未建立时，明确记录无增益或证据不足；不把仿真成功率、验证损失或解释流畅度作为实机提升。
