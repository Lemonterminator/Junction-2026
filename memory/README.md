# AI 共享记忆 / Shared AI memory

这是随 Git 同步的项目记忆，供队友、Codex、Claude 和其他 AI 使用。
它通过文件共享上下文，不会自动读取或同步其他聊天记录、账号记忆或未推送的改动。

| 文件 | 用途 |
| --- | --- |
| [PROJECT.md](PROJECT.md) | 稳定项目事实、来源入口和待确认事项 |
| [STATUS.md](STATUS.md) | 当前进度、验证证据和下一步 |
| [DECISIONS.md](DECISIONS.md) | 已采用的决策及原因；提案要单独标注 |
| [handoffs/](handoffs/) | 每次工作交接，一项任务一个文件，减少多人编辑冲突 |

开始工作：读取以上前三份文件，按任务需要读取交接记录与引用的资料。
结束工作：更新状态；有长期决策时追加决策；需要交接时复制
[交接模板](handoffs/TEMPLATE.md)，写明日期、作者、改动、检查和下一步。

共享步骤：将明确的文件加入 Git，提交到自己的功能分支，经团队流程合并；其他人
pull 后读取。尚未提交或尚未合并的工作必须在交接中标注所在分支与提交，不能写成团队已同步。
并发工作优先新增不同交接文件；不要用旧副本覆盖整份 STATUS。

凭证、原始数据、模型、完整聊天记录和私人账号信息不进入共享记忆。临时私人笔记可用
被忽略的 `*.local.md`。过时的事实保留历史并写明被何时、什么证据替代。
